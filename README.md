# Marine litter analysis — Arraial do Cabo

Reproducible reanalysis of marine-litter data collected at Praia Brava and
Ilha do Pontal, Arraial do Cabo, Rio de Janeiro, Brazil.

Author: Luciano Rapagnã
([ORCID 0000-0002-9009-4463](https://orcid.org/0000-0002-9009-4463)).

## Official data source

The analysis uses `data/raw/planilha_organizada.xlsx` as its official and
immutable input. All processed datasets, tables, figures, and statistical
results are generated from that file by scripts in this repository.

## Run in PowerShell

Open this folder in VS Code, start an integrated PowerShell terminal, and run:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\run_analysis.ps1 -Stage validate
```

To reproduce every analysis:

```powershell
.\run_analysis.ps1 -Stage all
```

In VS Code, the same commands are available through **Terminal → Run Task**:

- `Validate official data`
- `Run complete analysis`

## Project structure

- `data/raw/`: immutable source data.
- `data/processed/`: standardized data generated by scripts.
- `scripts/`: validation, analysis, and figure-generation code.
- `outputs/tables/`: publication-ready tables.
- `outputs/figures/`: publication-ready figures.
- `reports/`: statistical and reproducibility reports.
- `docs/`: data dictionary and analytical decisions.
- `notebooks/`: legacy notebook retained for provenance; not used by the new
  workflow.

## Current analytical workflow

- Integrity validation and explicit Portuguese-to-English variable mapping.
- Descriptive summaries retaining all 24 transects.
- Composition tables by beach and season.
- Hellinger PCA for compositional structure.
- Exploratory K-means comparison using silhouette scores.
- Bray–Curtis PERMANOVA on eight aggregated beach–campaign units.
- Exact restricted permutations: beach labels are swapped within campaigns and
  campaign labels are permuted within beaches.
- No beach × campaign interaction test because the aggregated design has zero
  residual degrees of freedom.
- Publication figures exported as PNG and PDF.

The PCA figure follows a persistent publication style with group ellipses,
zero-reference axes, variable vectors colored by contribution, and external
legends. Running the complete workflow always regenerates this format.

The K-means figure is likewise regenerated in English with cluster-specific
colors and marker shapes, short sample labels, 68% confidence ellipses when
estimable, and enlarged cluster centroids. The accompanying PCA-score table
maps each short label to its beach, season, and transect.

## Version history

- **1.1.1 (2026-11-26)** — Same data and results as 1.1.0. The Zenodo
  archive of 1.1.0 (10.5281/zenodo.24541764) included two files unrelated to
  the dataset by mistake and was withdrawn; 1.1.1 replaces it.
- **1.1.0 (2026-11-25)** — Corrected official workbook (AD-007): Ilha do Pontal
  campaign labels fixed (they had been reversed), 29 omitted metal fragments
  added (2,950 items in total), and the `fragments` column renamed
  `rubber_fragments`. All outputs regenerated. Heatmap labels and CCI threshold
  labels corrected; the sampling-design schematic now shows the 15 contiguous
  sectors and the random selection of three per campaign. The transect-level
  PERMDISP is no longer reported. `scripts/03_build_results_section.py` and
  `scripts/05_build_response_letter.py` are drafting helpers from version
  1.0.0 with hard-coded text; they were not updated and their outputs are not
  part of this release.
- **1.0.0 (2026-07-23)** — First archived release.

## Reproducibility rule

Never edit files in `data/raw/`. If the source workbook changes, replace it
deliberately, record the new SHA-256 hash, and rerun the complete workflow.

## Status

The complete workflow has been executed successfully from PowerShell. Density
and CCI use 50 m² per transect, as documented in
`docs/analysis_decisions.md`.
